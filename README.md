# Emoji Translator Android App

## Overview
Emoji Translator is an Android application developed using Java and Android Studio. The app converts user-entered text into emojis in real time, providing an engaging and interactive messaging experience.

## Features
- Real-time text to emoji conversion
- Simple and intuitive UI
- Fast translation using HashMap-based lookup
- Lightweight and beginner-friendly Android project

## Tech Stack
- Java
- Android Studio
- XML
- Android SDK

## How It Works
The application monitors user input through a TextWatcher and replaces predefined keywords with their corresponding emojis using a HashMap.

## Installation
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Run on emulator or Android device
